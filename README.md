# QUANTO TÁ

Registro semanal dos preços da cesta básica no Pão de Açúcar (São Paulo), sempre com as mesmas marcas.

- `index.html`: a página do site.
- `precos.json`: o histórico. Uma entrada nova é adicionada toda segunda-feira de manhã.
- `logo.png`: o logo.

Itens: arroz Camil 5 kg, feijão carioca Camil 1 kg, ovos brancos grandes (12 un.), leite Italac integral 1 L, óleo de soja Liza 900 ml e acém (preço por kg).
